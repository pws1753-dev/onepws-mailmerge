PRIVACY & DATA

A workspace you control.

Gmail send permission and your account email only. We do not request inbox reading.

Contacts and message content go directly to Google when you send. No analytics or remote fonts.

When off, this workspace is kept in browser session memory and cleared when Chrome exits or the extension reloads. Delivery receipts and saved templates remain local until cleared. Local storage is not encrypted by this extension; use a trusted Chrome profile.

Clear saved data

Remove this workspace, saved templates, and delivery receipts, and disconnect Gmail. Previously sent emails remain in Gmail. Clearing receipts removes duplicate-send protection for old campaigns.

To revoke access at Google too, remove this app from your Google account connections.
CONNECTION SETUP

Your account, connected.

Your extension ID:

  1. Enable the Gmail API in your Google Cloud project.
  2. Set up Google Auth Platform branding and audience. Testing apps require approved test users; production publication and verification are separate steps.
  3. Create a Chrome Extension OAuth client using the extension ID above.
  4. Run node scripts/configure.mjs YOUR_CLIENT_ID.apps.googleusercontent.com from the extension folder.
  5. Reload the extension at chrome://extensions, reopen OnePWS, and choose Connect Gmail.

See README.md for full instructions. No client secret or separate mail server is needed.
